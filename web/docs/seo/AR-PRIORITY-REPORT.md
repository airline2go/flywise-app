# تقرير أولويات SEO العربي — Airpiv

> **المصدر:** بيانات Google Search Console للفترة **01/09/2026 → 12/09/2026**، مصنّفة عبر محرك
> `lib/seo/` (normalize → classify → report) بعد توسيعه ليشمل **كل أنواع الصفحات**
> (مسارات / مدن / مطارات / شركات طيران / بلدان / مدونة / الرئيسية) بدل `/flights/` فقط.
> ثراء البيانات مأخوذ حيًّا من `api.airpiv.com` (تشخيص Phase 0). **لا توجد أرقام مختلقة.**

## كيف يُعاد توليد هذا التقرير

```js
const { buildOpportunityReport } = require('./lib/seo/report.js');
// rawRows = صفوف GSC الخام (page + impressions + position [+ clicks])
const report = buildOpportunityReport(rawRows); // يشمل الآن كل أنواع الصفحات
```

أو ألصق تصدير CSV من Search Console في لوحة الأدمن (`/admin` → SEO opportunities)؛
المسار `app/admin/api/seo-opportunities` يستهلك المحرك نفسه.

## التصنيف الآلي (من بياناتك الفعلية)

عتبات المحرك: `BREAKOUT` = مركز ≤5 وظهور ≥10 · `VERY_HIGH` = ظهور ≥40 ومركز ≤12 ·
`HIGH` = ظهور ≥20 ومركز ≤15 · `NORMAL` = لها بيانات دون عتبة · `LOW` = مركز >25 وظهور <5.

## الخلاصة: أين توجد القيمة فعليًا

البنية والقوالب والمحتوى العربي ممتازة أصلًا. نقاط الضعف الحقيقية **بيانات خادمية**،
مرتّبة حسب الأثر:

1. 🔴 **`/ar/flights/mxp-muc` محجوبة (noindex) لنقص البيانات** رغم ظهورها الفعلي —
   أعلى فرصة ملموسة. تتطلب إصلاح جمع بيانات المسار في `flywise-server`.
2. ⚠️ **إثراء المطارات** (مسافة للمركز/ترمينال/مواصلات) — BRE/KWI وكل المطارات.
3. ⚠️ **إثراء شركات الطيران** (دولة/مركز التشغيل) — EN/KL وكل الشركات.
4. ⚠️ **تضارب سعر `muc-gva`** — تحقق من عدم عرض سعر مضلّل.
5. 🟢 **صفحات BREAKOUT (مركز 1–4)**: تحسين CTR فقط عبر title/description — بلا مساس بالمحتوى.

## ما الذي تغيّر في الكود لإصدار هذا التقرير

- `lib/seo/normalize.js`: `entityFromUrl()` جديد يتعرّف على كل أنواع الصفحات ويضيف
  حقل `pageType`؛ اشتقاق اللغة يدعم البادئة العارية `/ar`. سلوك `/flights/` وحقل
  `slug` بلا تغيير (متوافق رجعيًا).
- `lib/seo/report.js`: يمرّر `pageType` في كل صف.
- اختبارات: `test/gsc-entity-coverage.test.mjs` (جديد) + تحديث تأكيدين قديمين كانا
  يوثّقان إسقاط صفحات المدن/الرئيسية.
